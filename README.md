# Quiz Application

## Description

A simple Quiz Application that allows users to answer multiple-choice questions and track their score.

## Features

- Multiple-choice questions stored in an array of objects
- Display questions and answer options
- Track and display the running score
- Show the current question number
- Show a final results screen
- Display the final score
- Review the correct answers
- Restart the quiz

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click **Start Quiz** to begin.
